# Weekly Satirical Poem Pipeline — Design Spec

## Overview

Automated weekly pipeline that generates a satirical poem about Bulgarian bureaucracy, creates an illustration, publishes it to gisheto.com, and posts to social media via Buffer.

## 1. Content Generation (Gemini API)

### Style Guide

The poem follows the Bulgarian satirical feuilleton tradition, combining:

**Voice & Tone:**
- Иво Сиромахов's compressed feuilleton form — dense as a joke, bitter irony masked as casual observation
- Еленко Еленков's documentary absurdism — real procedures described in such excruciating detail that no exaggeration is needed
- The "Евала бе, митница" tone — amused resignation, not outrage
- Tech-bureaucracy fusion (a la kolev.info) — systems that exist on paper but actively discourage use

**Character & Language:**
- Invented character names hinting at their fate (министър Технологиев, Живко Живев, Разводин Разделев)
- Bulgarian particles and texture (бе, ба, де, евала, Българска работа)
- Escalating absurdity — starts plausible, ends impossible
- Sometimes darkly sad underneath the comedy
- Mix of dialogue and narration
- Self-deprecating national humor — mocking with affection, not contempt (Donio Donev's principle)

**Structure:**
- Short feuilleton format (300-600 words)
- Hugo-compatible markdown with proper frontmatter
- SEO-friendly title, description, and keywords in Bulgarian

### Topic Selection (Hybrid)

1. Check `content/topics-queue.txt` for manually queued topics
2. If empty, Gemini picks from curated institution list: НАП, НОИ, КАТ, ТЕЛК, община, митница, нотариус, кадастър, ДНСК, МВР, ГРАО, Агенция по вписванията, пощи, ЧСИ, ДКС, etc.
3. Topics are checked against `content/topics-history.json` to prevent repetition
4. After generation, the used topic is appended to history

### Gemini Model

- Model: `gemini-2.5-flash` (fast, cost-effective, good for creative text)
- API Key: stored as GitHub secret `GEMINI_API_KEY`

## 2. Image Generation (Canva API via MCP)

### Style

- Donio Donev style: minimalist black-and-white ink cartoons, bold lines, exaggerated figures
- All text on images in Bulgarian
- Sometimes a GIF instead of static image — AI decides based on content (looping actions like endless queues work great as GIFs)
- Image prompt generated by Gemini based on the poem content

### Process

1. Gemini generates an image prompt describing the scene in Donio Donev style
2. Canva API generates the design (poster type)
3. Export as PNG (Canva's reliable export format)
4. Save to `static/images/{slug}.jpeg`

### Note on Canva API in GitHub Actions

Canva MCP tools are available in Claude Code but not directly in GitHub Actions. Two options:
- **Option A:** Use Gemini's image generation (requires paid plan upgrade)
- **Option B:** Pre-generate images via Claude Code session, or use the GitHub Actions workflow to call Canva's REST API directly

**Decision:** Start with Option B — the workflow calls Canva's REST API. If that proves unreliable, fall back to a manual Claude Code step for image generation.

## 3. Publish to Site (Git + GitHub Actions)

### File Creation

The script creates:
- `content/article/{slug}.md` — Hugo markdown with frontmatter:
  ```yaml
  ---
  title: "Generated title"
  date: YYYY-MM-DD
  description: "Generated description"
  draft: false
  featured_image: "/images/{slug}.jpeg"
  image_alt: "Generated alt text"
  keywords:
    - keyword1
    - keyword2
  ---
  ```
- `static/images/{slug}.jpeg` — the illustration

### Deploy

- Script commits both files and pushes to `main`
- Existing `deploy-hugo.yml` workflow handles build and deploy
- Site live at gisheto.com within ~2 minutes

## 4. Social Media Post (Buffer API)

### Format

- Post type: Image/GIF + teaser text + link
- Teaser: 2-3 sentence hook from the poem + link to full article
- Image: the Donio Donev illustration attached to the post
- All text in Bulgarian

### Buffer Integration

- API endpoint: `https://api.bufferapp.com/1/updates/create.json`
- Auth: Buffer API token stored as GitHub secret `BUFFER_API_KEY`
- Profile ID: fetched via `https://api.bufferapp.com/1/profiles.json` (the Gishe page profile)
- Buffer handles optimal posting time via its built-in scheduling
- Posts to: Facebook page "Гише без крайност"

### Post Timing

- Buffer's "optimal timing" feature posts when the audience is most active
- Alternatively, schedule for peak Bulgarian Facebook hours: 12:00-14:00 or 18:00-20:00 EET

## 5. Weekly Schedule (GitHub Actions Cron)

### Workflow: `generate-poem.yml`

```
Trigger: cron schedule — Wednesday 10:00 UTC (12:00 Sofia time)
         + manual workflow_dispatch

Steps:
  1. Checkout repo
  2. Setup Python 3.12
  3. Install dependencies (google-genai, requests, Pillow)
  4. Run generate_poem.py:
     a. Read topics-queue.txt → pick topic or let Gemini choose
     b. Check topics-history.json for duplicates
     c. Call Gemini API → generate poem markdown
     d. Call Gemini API → generate image prompt
     e. Call Canva API → generate illustration
     f. Export and download image
     g. Write .md file and image to repo
     h. Update topics-history.json
  5. Commit and push to main (triggers deploy)
  6. Wait 3 minutes for deploy
  7. Run post_to_buffer.py:
     a. Read the new article's metadata
     b. Compose social media post (teaser + link + image)
     c. POST to Buffer API
  8. Log results
```

## 6. Manual Controls

- **Add a topic:** Edit `content/topics-queue.txt` — add one topic per line
- **Skip a week:** Disable the workflow in GitHub Actions UI
- **Force generate:** Trigger workflow manually via GitHub Actions "Run workflow"
- **Review before publish:** Change workflow to create a PR instead of pushing directly to main
